# Portfolio Website - Viraj Lakshitha Adhikari

## 📌 Overview
A modern, responsive portfolio website built with React that showcases my skills, projects, and experience as a Full Stack Software Engineer.

## 🚀 Features
- **Responsive Design**: Works on all devices (mobile, tablet, desktop)
- **Smooth Animations**: CSS animations and interactive elements
- **Interactive Navigation**: Smooth scrolling with active section highlighting
- **Project Showcase**: GitHub integration with project cards
- **Interactive Map**: Location display using Leaflet.js
- **Dark Theme**: Cyberpunk-inspired design with neon accents

## 🛠️ Tech Stack
- **Frontend**: React, Babel (CDN version)
- **Styling**: CSS3 with custom properties
- **Icons**: SVG icons
- **Map**: Leaflet.js
- **Fonts**: Google Fonts (Inter, Space Grotesk)

## 🎨 Design Elements
- **Color Scheme**: Dark theme with neon accents (#00f5ff, #ff00ff, #00ff88)
- **Typography**: Inter (body) & Space Grotesk (headings)
- **Animations**: Fade-ins, floating cards, pulse effects
- **Components**: Navigation, Hero, About, Experience, Projects, Skills, Contact, Footer

## 📱 Sections
1. **Hero**: Introduction with animated tech stack
2. **About**: Personal overview with statistics
3. **Experience**: Timeline of professional roles
4. **Projects**: GitHub project showcase
5. **Skills**: Technical skills with categories
6. **Contact**: Contact info with interactive map
